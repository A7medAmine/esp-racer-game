INSTALL FIRMWARE

Put the controller firmware on your NodeMCU straight from the browser. No Arduino IDE needed.

  1. Plug the NodeMCU into this computer with a data USB cable (some cables only charge).
  2. Close the game tab or press Disconnect there, so the USB port is free.
  3. Click the button below, pick the port (often CP2102 or CH340), then Install.
Your browser can't flash devices. Use Chrome or Edge on a computer. This page must be opened from http://localhost (run start-game) or over https.

Need the old version 1.0 (joystick only, no paddles or vibration)? Version 1.1 still works with the joystick, so you normally don't need this.

No port shows up? Install the USB driver for your board's chip: CP2102 or CH340. If installing hangs on "Connecting", hold the FLASH button on the board while it starts. This page needs internet once to load the installer.
